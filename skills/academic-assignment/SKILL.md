# academic-assignment

Toolchain and standards: `../academic-core/` (`standards/filing.md`). Ask directly for what you need rather than
guessing: **subject, assessment type, the question or prompt, citation style, word count, due date, any rubric.**

## Hard integrity rules (no exceptions)
- **Never fabricate a citation** — author, year, title, journal, DOI or page. A plausible fake reference is the worst
  failure this skill can produce.
- **A citation you did not see returned is a fabricated citation.** Every reference must trace to a search result or a
  page you actually opened in this session (web search, a database tool, or text/links the student supplied). If you
  have no search capability, say so and work only from sources the student provides; mark anything else
  `UNVERIFIED — confirm before submission` and keep it **out** of the reference list.
- If a search returns nothing usable, say so and stop; an empty result is a finding. Never fill the gap from memory.
- Label preprints as preprints; flag retracted or contested work.
- **No submittable prose.** This produces research and structure; any draft text is a scaffold for the student to write
  over. Say so in the output. Quote sparingly (short quotes only); paraphrase with attribution.
- Match the required citation style exactly (APA 7, Harvard, MLA, Chicago…). Unstated → ask.

## Steps
1. **Course material before the open web:** the student's lecture notes, readings and rubric first (the marker rewards
   engagement with the unit's material), then outward to scholarly sources.
2. **Sources:** prefer peer-reviewed and primary work; use citation counts to find seminal papers; read the abstract or
   full text before relying on a source; note its strength (design, sample, limitations).
3. **Output, in this order:**
   1. **Research question** restated precisely (and the thesis options).
   2. **Argument map** — claims, and the evidence for each.
   3. **Annotated sources** — full citation + two lines on what it contributes + how strong it is.
   4. **Gaps** — what the evidence does not support; name it, don't paper over it.
   5. **Counter-evidence** — the strongest case against the thesis. Mandatory.
   6. **Plan** — section outline with word budgets mapped to the rubric criteria.
   7. **Reference list** in the required style — verified entries only.
4. File via `standards/filing.md` (artifact `assignment`): `[Assignment] — Research Pack.md` and `— Plan.md`; confirm the
   path first; never overwrite without asking.
5. Confirm: sources verified N, unverified N (listed), gaps named, destinations written / skipped (reason).
