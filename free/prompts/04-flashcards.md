# FLASHCARDS — exam-grade cards, importable into Anki (paste this, then paste the finished note)

GROUND RULES (apply throughout)
- You have no code or file tools here. Never claim you ran a script, rendered a file, or checked something "by tool". Say "checked by reading" for checks you do yourself.
- Never invent a citation, study, statistic, quote or figure value. If the material does not contain it and you are not certain, leave it out and tell me.
- Subject content only: leave out lecturer identity, assessment weighting and unit logistics.
- If something you need is missing (subject, lecture, outcomes, spelling, citation style), ask me ONE short question before starting.
- Spelling: [en-AU / en-GB / en-US — set once].

Source: only the note I paste. Make cards for: every definition · every named theorist/citation · every study (aim / method / findings / significance / limitations) · every case · the named specifics of each worked example · every comparison and commonly-confused pair · every examiner-level distinction. One testable idea per card; the front forces retrieval (a question or cue), never recognition.
Minimums: dense lectures at least 25 cards, lighter ones at least 12, and at least 3 per section. Cross-check that every heading in the note has cards; add what is missing.

OUTPUT 1 — a tab-separated block I can copy straight into a text file (one card per line: front, then a TAB, then back; no header; use <br> for line breaks inside a card). Put it in a single code block.
OUTPUT 2 — the same cards as a readable list grouped by outcome.

Anki import: save the code block as cards.txt, then Anki > File > Import, field separator Tab, "Allow HTML in fields" on.
End with: "Checked by reading: every note heading has cards [yes/no]; count [n]; anything I could not verify: [list]."
